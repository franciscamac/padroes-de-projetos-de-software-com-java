# Curso de Padrões de Projeto em Java

Neste curso, vou ajudá-lo a entender por que alguns sistemas desenvolvidos em Java são mais flexíveis, escaláveis e fáceis de manter do que outros. Você aprenderá como os padrões de projeto e os princípios de design podem transformar sua forma de desenvolver software, tornando suas aplicações mais organizadas, reutilizáveis e preparadas para evolução.

## Conteúdo do Curso

O curso está dividido em **5 tópicos principais**:

### 1. Padrões GoF de Criação

Estudo dos padrões responsáveis por desacoplar e organizar a criação de objetos em Java, proporcionando maior flexibilidade e reutilização de código.

**Padrões abordados:**
- Factory Method
- Abstract Factory
- Builder
- Prototype
- Singleton

### 2. Padrões GoF Estruturais

Apresentação dos padrões utilizados para organizar a estrutura das aplicações, facilitando adaptações e extensões sem a necessidade de grandes refatorações.

**Padrões abordados:**
- Adapter
- Bridge
- Composite

### 3. Padrões GoF Comportamentais

Exploração dos padrões focados na modularização de comportamentos e na adaptação de regras de negócio de forma simples e sustentável.

**Padrões abordados:**
- Observer
- Strategy
- Command

### 4. Padrões GRASP

Aprenda a distribuir responsabilidades corretamente entre as classes e componentes do sistema, criando aplicações mais robustas, coesas e de fácil manutenção.

**Princípios abordados:**
- Baixo Acoplamento (Low Coupling)
- Alta Coesão (High Cohesion)


### 5. JPA e JEE

Utilização das principais tecnologias da plataforma Java para desenvolvimento de aplicações corporativas.

**Tópicos abordados:**
- Persistência de dados com JPA
- Lógica de negócio com JEE
- Aplicações no padrão MVC
- Escalabilidade, manutenção e segurança

## Objetivo

Ao final do curso, você será capaz de identificar problemas de arquitetura, aplicar padrões de projeto de forma estratégica e desenvolver sistemas Java mais organizados, reutilizáveis e preparados para crescer de maneira sustentável.
